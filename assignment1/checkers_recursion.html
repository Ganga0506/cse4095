Untangling the checkers

n red checkers sit to the left of n black checkers. The only move allowed is swapping two neighbours. Watch a recursive strategy turn the block of colours into an alternating row, one adjacent swap at a time.

solve(offset, size):
  if size ≤ 1: return  # already alternating
  slide the first black checker left until it sits right after the leading red one
  solve(offset + 2, size − 1)  # same puzzle, one size smaller
